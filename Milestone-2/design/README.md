# UML authoring handoff

Six editable PlantUML sources describe the prototype. The course requires original .vpp files. Recreate the diagrams in Visual Paradigm with the same participant names, messages, alt/loop fragments, operations and multiplicities. Save the project as PearlMart-B54-M2.vpp, export the diagrams and verify the project opens on another member's computer. PlantUML files are not native Visual Paradigm projects.
